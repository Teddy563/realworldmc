# RealWorldMC 1.0.2

Downloads and setup: [realworldmc.com](https://realworldmc.com/)

## New
- On Minecraft 1.21.1, `/earth fly` enables flight without an elytra. Steve glides while moving and returns upright when slowing down. Creative singleplayer only.
- Use WASD to move, arrow keys to adjust speed, and Space/Shift to rise or descend. Normal rockets provide a boost.
- `/earth hud` shows or hides RW controls, messages and loading bars. Add `on` or `off` to set it explicitly.
- Experimental Minecraft 26.3 build.

## Fixed
- Node.js detection on macOS and Linux, including Homebrew and NVM installations.
- Flight getting stuck with Axiom and reversed left/right movement.
- Abrupt speed changes between local flight and orbit.
- Landing handoffs getting stuck and loading progress disappearing too early.
- Player visibility across chunks and depth conflicts that can cause Earth texture flicker.
- Terrain selection now looks ahead based on flight velocity while retaining current coverage.
- Service startup checks, browser preview paths and retries for failed tile requests.

`/rw` remains an alias for `/earth`. The redundant `/earth glide` command has been removed.

## Download
- **1.21.1:** recommended, Java 21. Includes native Street View, key setup and experimental orbital flight.
- **26.2 / 26.3:** experimental, Java 25. Includes terrain and browser Street View; no native setup screen, panorama or orbital flight yet.

Use the JAR in an existing Fabric profile, or import the matching `.mrpack` into Modrinth App or Prism. Back up your worlds and remove the previous RealWorldMC JAR before updating. Your saved keys remain in place.

Windows x64 includes Node.js. macOS and Linux need [Node.js 22 or newer](https://nodejs.org/en/download). Map features require internet access and your own provider credentials.

Shader compatibility still needs broader testing, including the known Bliss issue when returning from orbit. Propwash FPV compatibility on 26.3 is experimental and the mod is not bundled.
