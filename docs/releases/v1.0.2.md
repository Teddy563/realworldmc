# RealWorldMC 1.0.2

This update makes the local map service easier to start on macOS and Linux and adds a separate experimental Minecraft 26.3 download.

Get started at [realworldmc.com](https://realworldmc.com/) or follow the [setup guide](https://github.com/Teddy563/realworldmc/blob/main/docs/setup.md).

## What changed

- Find Node.js automatically from PATH, common Homebrew/Linux locations and NVM installations, including a custom `NVM_DIR`.
- Require Node 22 or newer, skip unsupported installations and compare NVM versions numerically. Explicit `nodeExecutable` settings still take priority; Windows x64 keeps its bundled runtime.
- Fix the browser map preview when the service runs from a versioned bundle.
- Check local ports directly before startup, avoiding false port-conflict errors caused by a timed-out HTTP health probe.
- Add an experimental Fabric 26.3 JAR and `.mrpack`, with Java 25 and Fabric API for 26.3. The port uses Minecraft's new `buildTerrain` and RenderPearl graphics APIs.
- Add Node detection checks on Windows, macOS and Linux, plus a regression check that failed tile requests remain retryable.

The Node discovery contribution comes from PR #2 by deloskiytbackup. Its unrelated preview redesign, cache changes and material changes are not included.

## Which download?

- **Minecraft 1.21.1:** recommended. Java 21, native Street View, masked setup and experimental space flight.
- **Minecraft 26.2 or 26.3:** experimental. Java 25, 3D terrain and browser Street View. No native key setup, in-game panorama or space mode yet.

Use the JAR for an existing Fabric profile, or import the matching `.mrpack` into Modrinth App or Prism. Keep one RealWorldMC JAR installed. Windows x64 includes Node; macOS/Linux users must install [Node.js 22+](https://nodejs.org/en/download) themselves.

## Propwash FPV

The 26.3 build is intended for testing alongside the **Fabric 26.3** version of [Propwash FPV](https://propwashfpv.com/). Propwash is a separate download and is not bundled. Camera, collision, recording and shader compatibility are experimental until tested together in a world.

## Updating

Back up your worlds, close Minecraft and replace the old JAR with the matching new one. Keys and controls remain in their existing files. Use a separate profile and a new test world for 26.3; do not upgrade your recording world just to try it.

Maps still need internet access and your own provider credentials. The known Bliss issue on returning from Earth orbit is not fixed by this update. See [validation and limits](https://github.com/Teddy563/realworldmc/blob/main/docs/release-1.0.2.md).
