# RealWorldMC 1.0.3

## Street View walking (Minecraft 1.21.1)

Walking starts enabled. WASD moves freely inside a 5 by 5 block square. Moving beyond 2.5 blocks from the panorama centre selects the connected stop closest to the movement direction (within 55 degrees) and prepares one photograph. Crossing 3 blocks commits travel once the photograph and destination ground are ready. The 7 by 7 outer boundary keeps the player near the current photograph while waiting. Missing links keep the current stop. Retreating into the centre cancels pending travel; failed requests require retreat before another automatic attempt.

V switches between walking and the fixed viewpoint. Arrow keys remain available. Perspective is approximate: a panorama has no full scene depth. Builds and entities remain at their geographic positions. Native walking is available on 1.21.1; 26.2 and 26.3 retain the browser companion.

## Xaero maps (Minecraft 1.21.1)

Optional OpenStreetMap imagery supports Xaero's Minimap 26.6.0 and World Map 1.47.0, individually or together. Missing or unrecognised versions leave the overlay disabled. This gate does not override Xaero's own loader requirements. The overlay requires an Earth region in the Overworld and preserves ordinary Xaero rendering elsewhere or while tiles load.

Downloads, native images and GPU textures are bounded and disposed on disconnect. Dateline wrapping and polar bounds are validated before allocation. The HTTP disk cache validates PNGs, separates providers, revalidates stale files and backs off on rate limits. OpenStreetMap credits remain visible. Automatic city labels/public Nominatim queries are deferred.

`osmMap` enables the overlay. `osmTileUrl` accepts an HTTPS tile template with `{z}`, `{x}`, `{y}`; configure only an appropriate provider. Existing saved settings receive defaults. The default provider remains OpenStreetMap, whose usage policy applies. No offline bulk download is implemented.

See [Google usage and billing](../google-maps-usage.md) and [validation](../release-1.0.3.md).
