# RealWorldMC 1.0.3

## Street View walking (Minecraft 1.21.1)

Walking starts enabled. Photo movement uses the same render interpolation as the camera and a smooth parallax limit, avoiding per-tick ground corrections. Nearby walking adds bounded horizontal photo movement (at most 0.45 metres of reprojection) and a 250 ms image fade in both modes. The player remains grounded in fixed-center mode too. Leaving the 3×3 area (1.55 blocks from center) prepares one connected photo in the movement direction (within 55 degrees). Continuing outward to 1.8 blocks from center commits travel when ready; the 5 by 5 area is the waiting boundary. Walking arrivals start one block behind the next center along the travel direction, preserving yaw and horizontal momentum. Terrain collision is bypassed only for nearby walking, at a fixed ground height. Missing links keep the current stop. Natural grass/dirt updates no longer appear as stray foreground tiles. The photograph ground plane follows camera height and third-person displacement; blocks remain one metre wide, but photo depth is still an approximation. Retreating cancels preparation without chat spam; arrival does not immediately prepare a return trip.

V switches between walking and the fixed viewpoint. Arrow keys remain available. The background is fixed to a single capture point: a panorama has no full scene depth. Builds and entities remain at their geographic positions. Native walking is available on 1.21.1; 26.2 and 26.3 retain the browser companion.

Sneak + Swap Offhand (normally Shift+F), with empty hands on the ground, enters Street View. Inside Street View it returns. Repeats are suppressed and there is a 2.5-second cooldown. `/earth streetkey off` disables this shortcut; `on` restores it.

The left HUD shows local monthly request attempts, Street View tile counts, the current photo's estimated tile cost, and an estimated allowance remaining. Terrain mode shows 3D root requests separately. `/earth hud off` hides the information. Counters start with this update and exclude earlier usage, other installations, other applications and account-wide usage. Failed attempts may overcount billing. Google Cloud remains authoritative. See [usage details](../google-maps-usage.md).

## Xaero maps (Minecraft 1.21.1)

The compact scoreboard panel removes repeated prefixes. `/earth usage off` hides only request counts; `/earth hud off` hides the entire optional panel and navigation arrows. Attribution and image reporting remain available.

Optional OpenStreetMap imagery supports Xaero's Minimap 26.6.0 and World Map 1.47.0, individually or together. Missing or unrecognised versions leave the overlay disabled. This gate does not override Xaero's own loader requirements. The overlay uses Earth regions in the Overworld and the separate photo-region anchor in Street View. Other dimensions remain isolated; ordinary Xaero rendering remains while tiles load.

Downloads, native images and GPU textures are bounded and disposed on disconnect. Dateline wrapping and polar bounds are validated before allocation. The HTTP disk cache validates PNGs, separates providers, revalidates stale files and backs off on rate limits. OpenStreetMap credits remain visible. Automatic city labels/public Nominatim queries are deferred.

`osmMap` enables the overlay. `osmTileUrl` accepts an HTTPS tile template with `{z}`, `{x}`, `{y}`; configure only an appropriate provider. Existing saved settings receive defaults. The default provider remains OpenStreetMap, whose usage policy applies. No offline bulk download is implemented.

See [Google usage and billing](../google-maps-usage.md) and [validation](../release-1.0.3.md).

### Earth return

`/earth back` prepares Earth at the current Street View geographic position. An upward third-person camera move uses the existing avatar, conceals the dimension transfer, then settles into the selected perspective. Earth mesh loading receives a bounded four-second reveal grace period after the destination chunk arrives; slow imagery can still appear afterward. `/earth back original` retains the original entry-point recovery behavior. No NPC is added to the save.
