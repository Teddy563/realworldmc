# RealWorldMC 1.0.3 — Street View, maps and navigation

## Street View

- Walk inside a 3×3 area around each photo, with limited parallax to reduce stretching and ground jitter.
- Begin preparing a connected photo after leaving the inner area. Continue outward to travel when it is ready, with a 5×5 waiting boundary.
- Arrive slightly behind the next photo center for smoother continued walking. Missing links keep you at the current stop; retreating cancels preparation.
- Switch between nearby walking and fixed-center navigation with V or `/earth walk on|off`.
- Added crossfades between photos in both navigation modes.
- Added matching camera animations for entering Street View and returning to Earth, restoring your previous camera perspective afterward.
- `/earth back` now returns to Earth at your current Street View location. `/earth back original` returns to the original entry point.
- Fixed incomplete, pinched 360 images caused by using the wrong tile zoom for smaller panoramas.
- Improved ground alignment and third-person camera handling. Natural grass/dirt changes no longer appear as stray foreground tiles.
- Kept navigation arrows gray, with yellow highlighting for the selected direction.
- Added the optional Sneak + Swap Offhand shortcut, normally Shift + F. Enter with empty hands while grounded; use it again to return. Toggle it with `/earth streetkey on|off`.

## Loading and usage

- Reduced the default image tile budget and bounded concurrent downloads, image assembly and memory use.
- Reuse fresh image tiles in a bounded memory cache when provider cache headers permit it. The HUD shows cached tiles and reuse counts.
- Added rate-limit backoff and protection against duplicate in-flight panorama assembly.
- Added local monthly request and tile counters, estimated remaining free usage, and estimated photo tile costs. Photorealistic 3D root requests are tracked separately.
- Usage figures are local estimates, not an account-wide balance. They exclude other applications, installations and earlier untracked usage; Google Cloud remains authoritative.

## Maps and terrain

- Integrated the Xaero map contribution and improved compatibility with Xaero's Minimap and World Map.
- Geographic overlays now follow the current Street View location as well as Earth regions.
- Improved dimension isolation, tile lifetime management, provider-aware caching, dateline handling and polar bounds.
- Made map attribution smaller and better positioned, removing the duplicate standalone gameplay notice.
- Improved damage rendering for scanned buildings with saved block-volume cuts and textured exposed edges.
- Fixed terrain filler protruding above scanned streets and stopped treating regenerated terrain as player edits. Ambiguous older edit records are retained for recovery.
- Protected terrain uploads against stale results and bounded pending uploads.

## Interface

- Matched the website palette across help, setup, HUD and command prefixes: dark gray backgrounds, brand-green accents and lighter green text.

- `/rw help` and `/earth help` now open a green, scene-visible command guide instead of filling chat with bold text.
- The guide includes paged commands and short descriptions. Selecting a command fills chat without executing it; Esc closes the guide. `help more` opens the advanced section.
- Replaced repeated HUD messages with a compact green panel.
- Added separate controls: `/earth hud on|off` for the optional HUD and arrows, `/earth usage on|off` for usage figures, and `/earth controls on|off` for key hints.
- Camera perspective remains independently selectable through `/earth camera first|back|front`.

## Compatibility and limitations

- These native Street View and interface improvements target Minecraft 1.21.1. The experimental 26.2 and 26.3 builds retain the browser companion; they do not include feature parity with the latest native update.
- Optional Xaero support targets Minimap 26.6.0 and World Map 1.47.0. Unsupported versions leave the custom overlay disabled.
- A panorama is a photograph, not a measured 3D scene. Ground projection and nearby movement remain approximate; source-image distortion cannot always be corrected.
- Earth imagery may continue loading after the return animation on slower connections.
- Automatic city labels and public Nominatim queries remain deferred.
- Shader-specific volumetric cloud occlusion is not fixed in this release.

## Validation

The update passed 39 service tests, 11 game tests, rendering and walking checks, and isolated Xaero/Iris/Sodium compatibility checks. The help guide was additionally built and visually checked in-game. The affected smaller panorama was verified to assemble as a complete image.
