# RealWorldMC 1.0.4

- New Fabric 1.20.1 download and base pack for Java 17. 1.21.1 remains recommended; 26.2 and 26.3 remain experimental.
- Fix a rocket/flight mixin conflict that could stop Minecraft from launching.
- Prepare neighboring terrain by geographic position and prevent movement into unrelated saved locations.
- Improve background tile processing, queue limits and worker recovery.
- Add render settings and release notes inside the native builds with `/earth settings` and `/earth update`.
- Add Polish interface strings and clearer installation instructions.

Choose the JAR or modpack matching your Minecraft version. Back up worlds and close Minecraft before replacing the old mod. Updates do not replace files automatically.
